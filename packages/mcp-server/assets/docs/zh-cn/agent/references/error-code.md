# 错误码参考

错误码按号段分组：**1xxx** 编译错误（阻断编译）、**9xxx** 编译警告（不阻断）、**2xxx** 运行时错误、**8xxx** 运行时警告、**3xxx** 语言服务错误、**7xxx** 语言服务警告。

## 编译警告（9xxx）

| 错误码 | 描述 |
|---|---|
| 9001 | 值从不变化；响应性标记冗余，将按 raw 处理 |
| 9002 | 顶层标识符可能在特定作用域中被遮蔽 |
| 9003 | `#scope` 无效：当前组件没有作用域样式 |
| 9004 | 衍生值是只读的，可变声明冗余；建议使用 `const` |
| 9005 | 对字面量 `const` 应用 `raw` 是冗余的 |
| 9006 | 该指令不需要值；提供的值将被忽略 |
| 9007 | 布尔属性被赋予了冗余值；将被忽略 |
| 9008 | `#html` 无值且内容为静态时没有实际作用 |
| 9009 | 组件事件监听上的事件标志无效；将被忽略 |
| 9010 | 非键盘事件上的键盘事件标志；将被忽略 |
| 9011 | 重复的事件标志；将被忽略 |
| 9012 | 缺少必需部分（动态属性、引用属性或事件监听）的 `<qk:spread>` 是多余的 |
| 9013 | `#scope` 多余：该组件已有真实祖先元素 |
| 9014 | 嵌套的 `raw` 调用冗余：参数已是非响应式读取，内层 `raw` 会被忽略 |
| 9015 | 未加 `#key` 的 `#for` 列表项含内部状态，列表更新时可能串位 |

## 运行时错误（2xxx）

| 错误码 | 描述 |
|---|---|
| 2001 | 特定用法（如 `#await`）接收的值不是 `Promise` |
| 2002 | `#for` 的值不可迭代 |
| 2003 | `#key` 的值存在重复 |
| 2004 | 超过最大递归更新深度（常见于异步副作用或监视器中的递归更新） |
| 2005 | 目标元素无效（不是 `Element`，或选择器找不到元素） |
| 2006 | `&group` 或多选 `<select>` 的 `&value` 必须是数组或 `Set` |
| 2007 | 无法渲染：给定值既不是组件函数，也不是兑现为组件函数的 `Promise` |

## 运行时警告（8xxx）

| 错误码 | 描述 |
|---|---|
| 8001 | 副作用/监视器执行时未收集到任何响应式依赖；该副作用将被销毁 |
| 8002 | 对只读或无效目标进行了赋值；赋值将被忽略 |
| 8003 | 在所属组件销毁后尝试创建内容（常见于组件移除后异步回调创建子组件或注册监视器/副作用）；创建已被忽略 |
| 8004 | 生命周期方法在对应阶段已过后注册（如组件挂载后在异步回调中注册 `onAfterMount`）；回调永不触发，注册已被忽略 |

## 语言服务（3xxx 错误 / 7xxx 警告）

| 错误码 | 描述 |
|---|---|
| 3001 | `Meta` 声明了未知成员（只允许 `props`、`refs`、`contexts`） |
| 3002 | `Meta` 或其成员不是对象类型（TypeScript） |
| 3003 | 找不到依赖 "qingkuai"；请确认已安装且可解析 |
| 3004 | 带泛型参数的导入类型被直接用作组件契约 `Meta` |
| 3005 | 类型不能从组件中导出；请移到外部 `.ts` 文件再导入 |
| 7001 | 经 JSDoc 声明的 `Meta` 不是对象类型（JavaScript） |
| 7002 | `@keyframes` 规则未被作用域化；建议在外部样式表中定义并从应用入口导入 |
