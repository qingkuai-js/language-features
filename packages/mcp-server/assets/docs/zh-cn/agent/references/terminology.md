# 术语参考

文档中通用的规范术语；推理或书写 `.qk` 代码时保持名称一致。

## 文件与实例

| 术语 | 含义 |
|---|---|
| 组件文件 | `.qk` 扩展名的文件；每个文件对应一个组件声明 |
| 组件实例 | 编译后创建的运行时对象；携带导出成员与内部状态。父级通过 `&handle` 获取，组件内部用内建 `instance` 访问；也是实例绑定运行时 API 的绑定参数 |
| 运行时包 | 入口为 `qingkuai` 的 npm 包：生命周期、上下文、监视器/副作用、性能优化、状态转换。组件文件内多数 API 是内建方法；外部使用需导入并以实例为第一个绑定参数 |
| 编译器包 | 入口为 `qingkuai/compiler` 的 npm 包；解析/编译 `.qk` 源码；供构建工具、语言服务与插件生态消费 |
| 内建标识符 | 无需声明、被编译器直接识别的保留标识符：对象类（`props`、`refs`、`slots`、`contexts`、`instance`）与方法类（内建方法） |
| 内建方法 | 组件文件内可直接使用的方法标识符（响应性标记、默认值、上下文写入、监视器/副作用、生命周期）；是编译期标记，编译为绑定当前实例的内部方法调用 |

## 属性与插值

| 术语 | 含义 |
|---|---|
| 静态属性 | 值为（带引号的）纯字符串字面量 |
| 动态属性 | `!` 前缀；值由插值表达式计算；绑定布尔值、对象等非纯字符串数据 |
| 引用属性 | `&` 前缀；用于值同步/引用传递的可写通道；可用于组件标签及 `input`/`textarea`/`select` 等原生标签；组件内部经 `refs` 访问并更新 |
| 事件 | `@` 前缀属性，绑定交互逻辑或对外暴露回调 |
| 插值属性 | 指令、动态属性、引用属性与事件的统称 |
| 插值块 | 模板文本或属性值中 `{expr}` 形式的内嵌 JS/TS 表达式 |
| 嵌入脚本块 | `lang-js` / `lang-ts` 标签包裹的、由编译器处理的区域 |
| 嵌入样式块 | `lang-css`/`lang-scss`/`lang-sass`/`lang-less`/`lang-stylus`/`lang-postcss` 标签区域；支持 `src` 与 `global` 属性 |
| 嵌入语言标签 | 上述八个 `lang-*` 标签 |
| 作用域 | 模板/脚本中标识符可访问的范围；影响插槽与指令上下文中的变量可见性 |
| `qk:spread` | 内置元素；指令的虚拟挂载点，不渲染为真实 DOM 元素 |

## 插槽与响应性

| 术语 | 含义 |
|---|---|
| 插槽出口 | 组件内用 `slot` 标签声明的占位位置 |
| 插槽内容 | 使用方传入的子内容；渲染在匹配的出口处 |
| 响应式 / 响应性 / 响应式值 | 追踪值变化并触发依赖更新的能力 / 该能力本身的抽象 / 具备该能力的具体数据单元 |
| 监视器 | 监听响应式值变化并以 `(pre, cur)` 运行回调 |
| 副作用 | 依赖响应式状态、状态变化后重新运行的逻辑 |
| 全局监视器 / 全局副作用 | 向运行时包 API 传入 `null` 作为绑定参数创建；不被自动清理；通过返回句柄手动管理生命周期 |
