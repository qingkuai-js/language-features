# 错误码参考

Qingkuai 的编译器和运行时可能会抛出附带错误码的诊断信息，帮助开发者快速定位问题。本节列出当前版本内置错误码及其含义，便于查阅与排查。错误码按功能类型分类，编号规则如下：

- 1xxx：编译错误，表示代码在编译阶段无法通过，通常需要开发者修正语法或逻辑问题；
- 9xxx：编译警告，提示潜在问题或不推荐的用法，但不会阻止代码编译；
- 2xxx：运行时错误，表示代码在运行过程中出现了致命问题，可能会导致程序中断；
- 8xxx：运行时警告，表示在运行过程中出现了非阻断性的异常行为，建议关注；
- 3xxx：语言服务错误，表示在 IDE 中使用语言服务功能时出现的问题，可能影响开发体验；
- 7xxx：语言服务警告，表示在 IDE 中使用语言服务功能时出现的非阻断性问题，建议关注。

通过错误码快速查找具体信息，可提升排错效率并更好地理解框架的行为。

## 编译警告

| 错误码 | 描述                                                                        |
| ------ | --------------------------------------------------------------------------- |
| 9001   | 值恒定不变，响应式标记冗余（将按原始值处理）                                |
| 9002   | 顶级作用域标识符在特定作用域中可能被覆盖                                    |
| 9003   | `#scope` 指令在当前组件没有作用域样式时无效                                 |
| 9004   | 衍生响应式值为只读，使用可变声明冗余（建议改为 `const`）                    |
| 9005   | 对字面量 `const` 进行 `raw` 标记是冗余的                                    |
| 9006   | 指令不需要值，提供的值会被忽略                                              |
| 9007   | 布尔属性提供了冗余值，冗余值会被忽略                                        |
| 9008   | `#html` 指令在无值且静态内容场景下无实际作用                                |
| 9009   | 组件事件监听器上的事件标志无效，会被忽略                                    |
| 9010   | 在非键盘事件上使用键盘事件标志无效，会被忽略                                |
| 9011   | 事件标志重复，重复项会被忽略                                                |
| 9012   | 缺少必要属性（如动态属性、引用属性或事件监听器）的 `qk:spread` 标签是冗余的 |
| 9013   | `#scope` 指令在此处不必要，因为该组件已有实际祖先元素                       |
| 9014   | 嵌套的 `raw` 调用冗余，参数已是非响应式读取，内层 `raw` 会被忽略            |
| 9015   | 未加 `#key` 的 `#for` 列表项含有内部状态，列表更新时可能串位                |

## 运行时错误

| 错误码 | 描述                                                                 |
| ------ | -------------------------------------------------------------------- |
| 2001   | 指定用途（如 `#await`）收到的值不是 `Promise`                        |
| 2002   | `#for` 指令值不可遍历                                                |
| 2003   | `#key` 指令值存在重复项                                              |
| 2004   | 超出最大递归更新深度（常见于异步副作用/监视器中的递归更新）          |
| 2005   | 目标元素无效（不是合法 `Element`，或无法通过选择器获取）             |
| 2006   | `&group` 或多选 `<select>` 的 `&value` 属性值必须是数组或集合        |
| 2007   | 无法渲染组件：给定值既不是组件函数，也不是解析为组件函数的 `Promise` |

## 运行时警告

| 错误码 | 描述                                                                                                              |
| ------ | ----------------------------------------------------------------------------------------------------------------- |
| 8001   | 执行副作用/监视器时未收集到任何响应式依赖，该副作用会被销毁                                                       |
| 8002   | 对只读或无效目标执行赋值操作，赋值会被忽略                                                                        |
| 8003   | 所属组件销毁后仍尝试创建内容（常见于组件移除后异步回调才执行创建子组件或注册监视器/副作用），该创建已被忽略       |
| 8004   | 生命周期方法在对应阶段已过后仍被注册（如挂载后在异步回调中注册 `onAfterMount`），回调永远不会触发，该注册已被忽略 |
